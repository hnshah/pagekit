# Vegan Dog Food Run Summary

## What this example is
A fully logged greenfield PageKit run for a trust-heavy consumer object.

## Starting object
Vegan dog food subscription service

## Initial problem
The object could not rely on convenience or subscription language alone.
The real issue was trust: ethical alignment without feeling reckless about the dog's health.

## What improved the run
The process worked because it centered:
- trust questions
- health reassurance limits
- ethical tension
- careful proof constraints

## What PageKit proved in this example
- the process transferred beyond software
- the system adapted to a different copy shape
- the source-improvement loop still mattered

## Best current homepage direction
**Dog food that matches your values and respects your dog's needs.**

## Why this example matters
This example shows that PageKit can handle a very different kind of homepage problem without forcing the same structure or tone as the software example.
