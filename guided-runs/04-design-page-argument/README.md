# Guided Run 04: Design the Page Argument

## Goal
Define the page's argument shape before drafting.

## Output
- page argument shape

## Core questions
- what must the visitor understand first?
- what must be earned next?
- what order should the argument follow?
- what sections actually belong on this page?
- what sections would be unnecessary or harmful?

## Quality checks
A strong page argument shape:
- fits the object
- does not rely on a default homepage rhythm
- makes trust and proof placement explicit
