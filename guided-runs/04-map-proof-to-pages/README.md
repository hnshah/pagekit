# Guided Run 04: Map Proof to Pages

## Goal

Decide what proof each page needs in order to feel specific and believable.

## Output

- proof map

## Core questions

- what proof burden does each page carry?
- what examples, trust objects or explanations belong where?
- where are the weak claims?

## Quality checks

A strong proof map:
- assigns proof by page job
- does not rely on generic persuasion language
- makes later drafting easier
