# Guided Run 05: Draft the First Page

## Goal

Draft one page from the system instead of improvising from scratch.

## Output

- first page draft

## Rule

Draft from the artifact chain.
Do not skip back to generic prompting.

## Inputs

- signal doc
- message spine
- page architecture
- proof map

## Quality checks

A strong draft:
- clearly belongs to the target page type
- reflects the right audience and proof burden
- inherits the structure of the upstream work

## What comes after

Later versions of PageKit should add:
- claim checking
- exhibit packaging
- page-family expansion
