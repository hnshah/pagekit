# Goal

Produce a first-page draft for a plant-based dog food subscription using the full PageKit v0.1 chain, fully logged.

## Why this run exists

The first-pass vegan-dog-food run (`runs/vegan-dog-food-first-pass/`) was only summary-logged and pre-assumed a homepage. It did not exercise the first-page-decision step, the page-argument-shape step or the claim-check step — none of which existed in the form they exist in now.

This run is the first real test of:
- the first-page-decision step on a trust-heavy non-software object
- the page-argument-shape step without a homepage default
- the claim-check step, run hard, on a draft that makes concrete product claims

## Success conditions

We finish this run with:
- a fully logged run per `frameworks/run-logging.md` (fully logged tier)
- a signal doc, message spine, first-page decision, page argument shape, proof map, first page draft, claim check
- an honest evaluation naming what stayed thin
- an evaluator pass that stress-tests the run from a skeptical angle
- a punch list of repo changes the run exposes

## Non-goals

- We are not trying to produce market-ready copy. The product object is intentionally fictional.
- We are not trying to re-validate that PageKit "works." We are trying to expose weak spots in the new steps.

## Object

Fictional brand: **Kind Bowl** — a plant-based dog food subscription.

Using a fictional brand lets us commit to concrete product facts without risking real overclaim about a real company. The concrete facts are stated in `sources/02-product-brief.md` and should be treated as the ground truth for this run.
