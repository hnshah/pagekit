# Run Goal

## What this run is for
Produce a first homepage draft for a vegan dog food brand — using the full PageKit process from signal doc through page draft. This is a clean-start run, independent of the prior vegan-dog-food-first-pass run.

## What success looks like
- A homepage that earns trust on the nutrition question before the values question — not the other way around
- Copy that does not default to "guilt-free" or "values-aligned" category language
- Honest treatment of the two trust barriers specific to vegan dog food: nutritional completeness and palatability
- Proof claims that stay within what is actually supportable
- A page that could convert both values-led and health-led visitors without compromising the argument for either

## What this run is not trying to do
- Serve every type of pet owner
- Compare against every vegan dog food brand on the market
- Write copy for the nutrition science page or an ingredients page — homepage only in this pass

## Starting conditions
No primary source materials. Signal draws from publicly observable owner discussion (Reddit, vegan communities, pet owner forums, Amazon reviews of vegan dog food products, vet Q&A forums). That limitation stays visible and constrains claims downstream.

## Fresh angle for this run
The prior run in this repo led with the values tension — "values without compromise." This run will test a different opening: the nutrition question first, values second. The hypothesis is that leading with "your dog can thrive on this" earns more trust than leading with "your values deserve alignment" — because the trust barrier is nutrition, not ethics. The values argument is easier to make once the nutrition argument is won.
