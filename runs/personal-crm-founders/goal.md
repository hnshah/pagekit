# Run Goal

## What this run is for
Produce a first homepage draft for a personal CRM product aimed at startup founders — using the full PageKit process from signal doc through page draft.

## What success looks like
- A homepage that speaks to the specific founder experience of losing relationship context, not generic CRM positioning
- Copy that does not default to sales CRM language or productivity category language
- Proof claims that stay within what is actually supportable
- Honest acknowledgment of where proof is still thin

## What this run is not trying to do
- Position against every CRM on the market
- Write copy for multiple pages
- Serve both founders and enterprise sales teams in the same draft

## Starting conditions
This is a first-pass run without primary source materials (no interviews, no reviews, no sales call transcripts). The signal doc will draw on known founder behavior patterns and publicly observable founder language. That limitation should stay visible throughout and constrain what claims the draft can make.
