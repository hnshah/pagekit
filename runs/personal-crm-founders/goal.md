# Goal

Produce a fully-logged PageKit run for Me CRM, a personal CRM for startup founders. The object is a training fiction with concrete facts committed upfront (no placeholders). The intended output is a first-page draft suited to the product's strongest argument, with the first-page decision made deliberately rather than defaulting to a homepage.

This run exists to demonstrate the fully-logged tier on a SaaS product aimed at a specific professional audience — a different category from the prior Verdel run.

## Success conditions

We finish this run with:
- a fully logged run per `frameworks/run-logging.md` (fully logged tier)
- a signal doc, message spine, first-page decision, page argument shape, proof map, first page draft
- a claim-check pass with severity recorded
- an honest evaluation naming what stayed thin
- an evaluator pass that stress-tests the run from a skeptical angle

## Non-goals

- Not building a sales or marketing CRM. Me CRM is explicitly not for high-volume outreach.
- Not producing copy for every page on the site — first page only.
- Not producing a UI spec or product roadmap.

## Object

Me CRM — a personal CRM for startup founders. Product name: Me CRM. Concrete facts committed in sources/02-product-brief.md.
