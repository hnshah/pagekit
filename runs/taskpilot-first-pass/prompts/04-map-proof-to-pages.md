# Prompt 04 — Map Homepage Proof

## Objective
Define the proof burden for the TaskPilot homepage before drafting copy.

## Model
GPT-5.4 via current OpenClaw session.

## Exact prompt

You are defining the proof burden for a homepage draft.

Your job is to map what the TaskPilot homepage can honestly support, what it can only suggest carefully and what it must avoid claiming.
Do not draft homepage copy yet.

Using the current TaskPilot materials, produce a homepage proof map with these sections:
1. proof the homepage can honestly carry now
2. proof the homepage does not yet have
3. safe credibility moves
4. risky or inflated moves to avoid
5. what the hero can say safely
6. what the product section can say safely
7. what the trust section can say safely
8. what still needs future validation

Output requirements:
- protect against overclaiming
- be honest about the thin proof layer
- make the next homepage draft safer and sharper

## Inputs expected
- signal doc
- message spine
- homepage architecture

## Failure modes to watch for
- invented proof
- fake customer confidence
- abstract claims with no grounding
