# Prompt 03 — Build Homepage-Oriented Page Architecture

## Objective
Turn the TaskPilot message spine into a homepage-oriented page architecture / page brief.

## Model
GPT-5.4 via current OpenClaw session.

## Exact prompt

You are turning a homepage-oriented message spine into a homepage architecture brief.

Your job is to define what the homepage needs to do before any copy is drafted.
Do not write the homepage yet.
Do not fill gaps with fake product detail.

Using the current TaskPilot materials, produce a homepage architecture brief with these sections:
1. homepage job
2. primary audience
3. visitor state on arrival
4. core message to land first
5. supporting messages
6. trust question the page must answer
7. sections the homepage likely needs
8. proof burden per section
9. risks if the page stays too abstract
10. constraints for the draft step

Output requirements:
- optimize for a homepage draft as the next step
- make the page job explicit
- keep uncertainty visible where product detail is still thin
- avoid turning the architecture into finished marketing copy

## Inputs expected
- refined signal doc
- message spine
- wedge-definition brief

## Failure modes to watch for
- vague homepage sections
- feature sprawl
- page architecture that sounds like copy
- hiding the missing proof/problem-mechanism issues
