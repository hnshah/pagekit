# Prompt 01 — Build Signal Doc

## Objective
Turn the currently available TaskPilot starter material into a stronger signal doc for homepage work.

## Model
GPT-5.4 via current OpenClaw session.

## Exact prompt

You are helping build a homepage through the PageKit process.

Your job in this step is only to strengthen the signal layer.
Do not write homepage copy yet.
Do not jump ahead to final positioning language unless it is clearly earned by the source material.

Using the available TaskPilot source material, produce a signal doc with these sections:
1. what the product appears to be
2. likely target audience(s)
3. recurring pains or friction
4. desired outcomes
5. trust questions or buying resistance
6. words/phrases that feel native vs generic
7. what still feels unknown
8. weak claims to avoid early

Output requirements:
- keep it concrete
- separate observation from assumption
- call out where the source material is still thin
- optimize for a later homepage, but do not draft the homepage

## Inputs expected
- current TaskPilot starter sources
- any existing working notes from the private PageKit repo

## Failure modes to watch for
- generic productivity language
- invented certainty about the buyer
- homepage-like copy sneaking in too early
- weak or inflated claims
