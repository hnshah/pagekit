# Prompt 05 — Draft Homepage

## Objective
Draft the first TaskPilot homepage from the current PageKit artifacts.

## Model
GPT-5.4 via current OpenClaw session.

## Exact prompt

You are drafting a homepage from a PageKit run.

Use the current TaskPilot artifacts:
- signal doc
- message spine
- homepage architecture
- proof map

Write a first homepage draft with these sections:
1. hero headline
2. hero subhead
3. primary CTA
4. problem section
5. product section
6. trust/credibility section
7. closing CTA section

Constraints:
- clarity over hype
- do not invent proof
- do not overstate the mechanism
- do not drift into generic task-software language
- keep the page anchored in momentum, slippage and coordination drag
- avoid AI slop
- avoid not-X-but-Y constructions

## Failure modes to watch for
- abstract concept language
- vague productivity promises
- fake confidence
- feature drift with no proof
