# TaskPilot Comparison Brief

## Why this source exists
One trust question keeps showing up:
why is this different from the tools people already have?

This source exists to force a clearer contrast.

## Core contrast
TaskPilot should not be framed as a better place to store tasks.
It should be framed as a better way to notice when important work is losing momentum.

## Existing-tool contrast
Existing tools are often good at:
- capturing work
- assigning work
- listing work
- planning work

The gap is often:
- seeing slippage early enough
- keeping follow-through visible
- reducing coordination drag once work is already in motion

## Homepage implication
The homepage should help the visitor feel:
- I already have places where work lives
- my real problem is not capture
- my real problem is momentum, follow-through and visibility

## Comparison warning
Do not overstate this contrast into a hard product claim we cannot prove yet.
Use it as a framing difference, not a winner-take-all claim.
