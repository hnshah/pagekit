# TaskPilot Product Brief

## Product name
TaskPilot

## Working product description
TaskPilot is a product we are using as the first greenfield PageKit test object.
For this run, the goal is not to pretend we already have rich market evidence.
The goal is to create a realistic enough source brief that lets us pressure-test the PageKit process from zero to homepage copy.

## Assumed category
Task and workflow software.
Potentially positioned around helping people keep work moving, stay organized and reduce coordination friction.

## What still feels unknown
- exact product mechanics
- exact buyer
- exact differentiator
- what proof exists
- whether the strongest angle is personal productivity, team coordination or operational clarity

## Why this is still usable
This is a valid PageKit test because greenfield cases are common.
The process should help narrow ambiguity instead of hiding it.

## Constraints for the run
- do not fabricate mature proof
- do not invent customer quotes
- do not pretend the positioning is already obvious
- use this ambiguity to test whether the signal and reduction steps are helpful

## Homepage implication
The first homepage pass should probably optimize for clarity around the job, audience and pain rather than polished conversion copy too early.
