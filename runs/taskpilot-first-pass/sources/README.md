# TaskPilot Sources

This run is being treated as a true greenfield PageKit run.

That means the source set starts here.
We are not importing prior mock materials.

## Purpose
Collect the raw material that will feed the TaskPilot signal doc.

## Source types to gather
- plain product description
- target audience notes
- problem framing
- desired outcomes
- competitor or category context
- words/phrases that feel native
- proof or trust constraints

## Rule
Keep source capture separate from synthesis.
Do not turn this folder into a message-spine draft by accident.
