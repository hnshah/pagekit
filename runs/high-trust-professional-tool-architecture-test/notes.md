# High-Trust Professional Tool Architecture Test

## Purpose
Test whether the improved PageKit prompt architecture stops defaulting to the same homepage shape.

## Test object
A high-trust professional software product where the first page might not want a generic homepage rhythm.

## What we are testing
- does the new first-page decision step work?
- does the new page-argument-shape step produce a more object-specific structure?
- does the system still quietly default to homepage sameness?

## Success condition
The output should show a page decision and argument shape that feel meaningfully tailored to the object rather than copied from prior homepage patterns.
