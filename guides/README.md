# Guides

These are fully self-contained prompt-path guides for people who want to run PageKit entirely inside a given tool.

## How to use these guides
Use one guide when you want to stay inside a single tool for the full artifact chain.
Each guide should be usable on its own without bouncing between multiple files.

## Difference from quickstarts
- quickstarts get you moving fast
- guides walk you through the full artifact chain in one place

## Available guides
- `chatgpt-prompt-path.md`
- `claude-prompt-path.md`
- `perplexity-prompt-path.md`
- `grok-prompt-path.md`
- `openai-prompt-path.md`

## Rule
The tool may differ.
The artifact chain does not.

The page shape should still be determined by the object.
These guides should not be read as one fixed homepage template.
